# The Miri gate's selection (tests/miri-owned.sh), which the reach map
# (tests/reach-map.sh) instruments and the mutation campaign's Miri layer
# judges on: one line per suite, its mutation domain (`all-features` or
# `no_std`, whose features tests/gate-common.sh's `domain_features` names), a
# target kind, the suite, and an optional test-name filter.
#
# `lib` selects the library's test binary by the module path it names;
# `test` an integration test binary; `abort` an integration test binary whose
# ignored tests each end their own process by aborting, run one at a time
# and required to abort (natively by SIGABRT, under Miri by its abnormal
# termination, with no undefined behavior reported). A filter is libtest's:
# it selects every test whose name contains it.
#
# The filters keep the resumable suite to the code whose unsafe operations
# are under test: the Slot cursors of BTreeMap, Map and symbolic CBOR; and
# the retained arena's staged growth, whose block is acquired, vacated into
# the arena and freed, refused at every admission and cancelled at every
# partial relocation. Fixed arrays are qualified by reclamation_owner, owned
# preparation by the owned suites. The decode scope's abort is witnessed in
# both domains: with std it is `std::process::abort`, without it a panic
# while panicking, code the all-features build never compiles.
